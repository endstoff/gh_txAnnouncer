# Ghostscripts txAnnouncer

Since I couldn't find any [txAdmin](https://txadm.in) announcements on the forums, I opted to craft this straightforward one. Within the *shared.lua* file, you have the freedom to customize the notification to your preference. Should you wish to change the language, you'll need to access the *server.lua* file.
